# SFX Pack — UI / Editorial Video

25 sound effects, grouped by editing function. All audio files are WAV, mono,
48 kHz, 16-bit PCM. Short cues were trimmed to the requested editing-friendly
lengths and given a 40 ms fade-out.

## Quick picks

- List reveal: `02-list-reveal/tick-ui.wav` or `click-soft.wav`
- Main transition: `01-transition/whoosh-fast.wav`
- Large number/stat: `03-stat-impact/impact-bass.wav`
- Positive conclusion: `04-positive/ding-success.wav`
- Clean UI scene: `06-ui-screen/notification-pop.wav`
- Finance stat: `07-money-growth/coin-clink.wav`
- Correct/wrong comparison: `08-compare/correct-positive.wav` / `error-buzz.wav`
- Editorial scene: `09-paper/page-turn.wav`

## Contents

| Group | Files | Intended use |
|---|---|---|
| 01 Transition | 4 | fast, soft, air, reverse variants |
| 02 List reveal | 3 | tick, subtle click, short pop |
| 03 Stat impact | 3 | punch, bass, wood thud |
| 04 Positive | 3 | success ding, bright chime, sparkle |
| 05 Build-up | 2 | cinematic riser, magical swell |
| 06 UI / screen | 3 | notification, typing, shutter |
| 07 Money / growth | 3 | coins, money bag, level-up |
| 08 Compare | 2 | correct and error cues |
| 09 Paper | 2 | page turn and pencil writing |
