# Optional primitives

Use these only when they improve the story. They are not defaults.

## Annotation callout

Use a serif-italic aside in the margin for one editorial insight or caveat. Connect it with a dashed curved leader. Keep to at most two callouts, outside the node field, and never use them as a substitute for a missing label.

## Sketchy variant

Use a subtle SVG turbulence/displacement filter for essays or informal explainers. Keep the layout, tokens, and connector rules unchanged. Do not use it for precision-heavy architecture, security, or data-model work.

## Terminal variant

Use a compact terminal window only when the subject is a CLI/tool workflow. Keep one accent, restrained chrome, and normal sans labels; terminal styling is a framing treatment, not a reason to use mono everywhere.

## Icons

Use monochrome, current-color icons for recognizable systems or actors. Icons support labels; they do not replace them. Prefer a small consistent set and avoid embedding arbitrary logos or screenshots from an imported source.
